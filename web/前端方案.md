# 网页端前端与后端接口补充方案

## 一、目标

在本项目新增网页端前端目录 `web`，使用 Vue 3、Vite、TypeScript、Element Plus、Axios、Vue Router 实现一个面向用户端 C 的网页界面。

网页端通过 Go 后端调用已在线的扩展端 A，完成工作区选择、用户令牌配置、聊天请求、流式聊天和历史记录查看。

本阶段只输出方案，不实施前端代码，不修改 Go 后端代码。

## 二、技术栈

前端技术栈：

- Vue 3（统一使用 Composition API）
- Vite（配置 dev proxy 解决本地开发 CORS）
- TypeScript（补全接口类型定义）
- Element Plus（封装少量业务组件）
- Axios（用于普通 JSON 请求，流式接口使用 Fetch）
- Vue Router（补充路由守卫策略）
- Vue I18n（提前定义文案 key 规范）
- Pinia（状态管理库）

## 三、页面布局

整体采用左右分栏布局。

### 左侧栏

左侧栏分为上下两部分。

#### 左侧上方：工作区列表

显示当前用户可访问且在线的工作区和扩展实例。

信息建议包含：

- 工作区名称。
- 工作区标识。
- 扩展实例标识。
- 在线状态。
- 最近连接时间。
- 当前会话标识。

交互要求：

- 点击工作区后，右侧聊天区切换到该工作区。
- 如果同一工作区有多个实例，支持选择具体实例。
- 支持刷新工作区列表。
- 工作区离线时禁用聊天输入。

#### 左侧下方：用户 token 设置

如果用户没有登录或没有设置接口令牌，显示登录按钮。

登录后显示：

- 当前用户标识。
- 当前接口令牌脱敏展示。
- 设置或更新接口令牌入口。
- 退出登录按钮。

令牌保存策略：

- 网页端只保存 C 调用 B 的 HTTP API token。
- token 默认保存在浏览器本地存储中（属于便利优先方案）。
- 显示时只显示前四位和后四位，中间使用星号；短 token 全部星号展示。
- 支持清除 token。
- 支持"仅本次会话保存"选项，使用 sessionStorage。
- 保存前必须明确提示风险：请勿在公共电脑或不可信环境保存 Token。
- 退出登录时必须清理 localStorage 和 sessionStorage 中的 Token。
- 注意：Base64 编码只能混淆，不能防止 XSS 攻击读取。

注意：这里的网页端 token 是 C 到 B 的 HTTP 鉴权令牌，不是 A 到 B 的 WebSocket token。

### 右侧聊天区

右侧分为上方聊天内容和下方输入框。

#### 聊天内容区

展示当前工作区的聊天消息。

消息类型：

- 用户消息。
- 助手正文。
- 推理片段，可配置显示或隐藏。
- 工具调用事件。
- 工具结果。
- 错误消息。
- 取消消息。
- 历史消息。

要求：

- 支持流式追加正文。
- 支持请求中状态显示。
- 支持滚动到底部。
- 支持清空当前会话显示。
- 支持加载当前项目历史记录。

#### 输入框区

输入框位于右侧底部。

交互：

- 输入消息。
- 发送普通请求。
- 发送流式请求。
- 支持自动发送开关。
- 支持回车发送，组合键换行。
- 工作区未选择、未登录、工作区离线时禁用。

## 五、前端路由设计

建议路由：

```text
/login
/chat
```

路由规则：

- `/login`：设置 HTTP API token。
- `/chat`：主聊天页面。
- 未设置 token 访问 `/chat` 时跳转到 `/login`。
- 已设置 token 访问 `/login` 时可跳转到 `/chat`。
- 启动时自动校验 token 有效性，token 失效时自动跳转 `/login`。
- 页面刷新时保持当前路由和状态。
- 404 或未知路由重定向到 `/chat` 或 `/login`。

路由守卫伪代码：

```typescript
// 前端初始化时
const authStore = useAuthStore();
await authStore.validateToken();  // 调用 GET /api/me 校验

// 路由守卫
router.beforeEach((to, from) => {
  if (to.path === '/chat' && !authStore.isLoggedIn) {
    return '/login';
  }
  if (to.path === '/login' && authStore.isLoggedIn) {
    return '/chat';
  }
});

// HTTP 拦截器
axios.interceptors.response.use(
  response => response,
  error => {
    if (error.response?.status === 401) {
      authStore.logout();
      router.push('/login');
    }
    return Promise.reject(error);
  }
);
```

## 六、前端状态设计

使用 Pinia 作为状态管理库。

建议状态模块：

### 认证状态

字段：

- `apiToken`：原始 token。
- `userId`：当前用户标识。
- `isLoggedIn`：是否已登录。
- `validating`：正在校验 token。
- `error`：错误信息。

注意：`maskedToken` 作为 getter 不作为持久状态存储。

### 工作区状态

字段：

- `workspaces`：工作区列表。
- `selectedWorkspaceId`：选中的工作区标识。
- `selectedInstanceId`：选中的实例标识。
- `loading`：正在加载。
- `polling`：是否正在轮询。
- `lastRefreshAt`：最近刷新时间。
- `error`：错误信息。

注意：消息 key 使用 `workspaceId:instanceId` 组合，避免同一工作区多个实例消息混淆。

### 聊天状态

字段：

- `messagesByWorkspace`：按工作区分组的聊天消息。
- `activeRequestId`：当前活动请求标识。
- `activeMessageId`：当前活动消息标识。
- `abortController`：请求取消控制器。
- `historyLoading`：正在加载历史记录。
- `error`：错误信息。

注意：使用 `AbortController` 管理流式请求，支持用户取消、切换工作区取消、退出登录取消、路由离开取消。

### 设置状态

字段：

- `language`：当前语言。
- `showReasoning`：是否显示推理片段。
- `autoSend`：是否自动发送。
- `theme`：主题偏好。

### 核心类型定义

```typescript
// 工作区实例
interface WorkspaceInstance {
  workspaceId: string;
  instanceId: string;
  sessionId?: string;
  connectedAt?: string;
  lastSeenAt?: string;
  state: WorkspaceState;
  metadata?: {
    workspaceFolders?: string[];
    workspaceName?: string;
    [key: string]: unknown;
  };
}

// 工作区状态枚举
type WorkspaceState = 'ready' | 'busy' | 'offline' | 'unknown';

// 聊天消息
interface ChatMessage {
  id: string;
  workspaceId: string;
  instanceId?: string;
  role: 'user' | 'assistant' | 'system' | 'tool';
  content: string;
  reasoning?: string;
  toolCalls?: ToolCall[];
  toolResults?: ToolResult[];
  createdAt: string;
  status: MessageStatus;
  source: 'current' | 'history';
  error?: {
    code?: string;
    message: string;
  };
}

type MessageStatus = 'pending' | 'sending' | 'streaming' | 'done' | 'error' | 'cancelled';

// 工具调用
interface ToolCall {
  id: string;
  name: string;
  arguments: Record<string, unknown>;
}

// 工具结果
interface ToolResult {
  toolCallId: string;
  result: unknown;
  success: boolean;
}
```

## 八、Go 后端需补充的 HTTP 与 SSE 端点

现有 Go 后端已有：

- `POST /api/chat`
- `POST /api/chat/stream`
- `POST /api/chat/history`
- `GET /health`

为了支持网页端，还需要补充以下端点。

### 获取当前用户信息

```text
GET /api/me
```

用途：

- 校验 API token 是否有效。
- 返回当前用户标识。

请求头：

```
Authorization: Bearer <apiToken>
```

响应（成功）：

```json
{
  "ok": true,
  "payload": {
    "userId": 1
  },
  "error": null
}
```

响应（失败）：

```json
{
  "ok": false,
  "payload": null,
  "error": {
    "code": "TOKEN_INVALID",
    "message": "Token 已过期或无效",
    "detail": "可选的调试信息",
    "requestId": "可选的请求追踪标识"
  }
}
```

未认证时返回四百零一。

### 获取在线工作区列表

```text
GET /api/workspaces
```

用途：

- 返回当前用户名下在线扩展端连接。
- 供左侧工作区列表展示。

请求头：

```
Authorization: Bearer <apiToken>
```

响应（成功）：

```json
{
  "ok": true,
  "payload": {
    "workspaces": [
      {
        "workspaceId": "工作区标识",
        "instanceId": "扩展实例标识",
        "sessionId": "会话标识",
        "connectedAt": "2026-05-12T00:00:00.000Z",
        "lastSeenAt": "2026-05-12T00:00:00.000Z",
        "state": "ready",
        "metadata": {
          "workspaceFolders": [],
          "workspaceName": "可选的工作区名称"
        }
      }
    ]
  },
  "error": null
}
```

响应（失败）：

```json
{
  "ok": false,
  "payload": null,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "未授权访问",
    "requestId": "xxx"
  }
}
```

错误码：

- `UNAUTHORIZED`：未认证或 token 无效
- `FORBIDDEN`：无权访问
- `INTERNAL_ERROR`：服务端内部错误

### 工作区事件 SSE

```text
GET /api/workspaces/events
```

用途：

- 前端实时感知工作区上线、离线、状态变化。
- 左侧列表不必频繁轮询。

SSE 详细说明：

- **心跳间隔**：建议服务端每三十秒发送一次 ping 事件
- **前端超时**：建议设置四十五秒无消息自动断开重连
- **重连策略**：断开后指数退避重连
- **鉴权方式**：原生 EventSource 不支持自定义 Authorization header，可选方案：query 参数传递 token、fetch 加 ReadableStream、或 cookie 鉴权（需配套 CSRF 防护）
- **前端收到断开事件后**：不自动清理选中工作区，提示用户选择其他在线实例

事件建议：

```text
event: workspace_connected
data: {"workspaceId":"xxx","instanceId":"xxx","state":"ready"}

```

```text
event: workspace_disconnected
data: {"workspaceId":"xxx","instanceId":"xxx"}

```

```text
event: workspace_state_changed
data: {"workspaceId":"xxx","instanceId":"xxx","state":"busy"}

```

```text
event: ping
data: {"timestamp":"2026-05-12T00:00:00.000Z"}

```

首版可以先不实现该 SSE，使用 `GET /api/workspaces` 轮询替代；但方案上保留该端点作为二期优化。

### 用户端聊天流式请求

```text
POST /api/chat/stream
```

网页端使用 Fetch 或原生流读取方式处理 SSE。

注意：Axios 浏览器端不适合直接消费 `text/event-stream` 流式响应，必须使用 Fetch 读取流，普通 JSON 请求继续使用 Axios。

请求头：

```
Authorization: Bearer <apiToken>
Content-Type: application/json
```

请求体：

```json
{
  "workspaceId": "工作区标识",
  "instanceId": "扩展实例标识",
  "message": "用户输入的消息"
}
```

响应类型：`text/event-stream`

流式事件协议：

```
event: message_start
data: {"requestId":"xxx","messageId":"xxx"}

```

```
event: content_delta
data: {"messageId":"xxx","delta":"助手回复的增量内容"}

```

```
event: reasoning_delta
data: {"messageId":"xxx","delta":"推理过程的增量内容"}

```

```
event: tool_call
data: {"messageId":"xxx","toolCall":{"id":"xxx","name":"工具名","arguments":{}}}

```

```
event: tool_result
data: {"messageId":"xxx","toolCallId":"xxx","result":{},"success":true}

```

```
event: error
data: {"code":"EXTENSION_ERROR","message":"错误信息","requestId":"xxx"}

```

```
event: done
data: {"messageId":"xxx"}

```

前端对每类事件的处理规则：

- `message_start`：创建消息对象，状态设为 `streaming`
- `content_delta`：追加到消息 content，状态保持 `streaming`
- `reasoning_delta`：追加到消息 reasoning（可选显示）
- `tool_call`：添加到 toolCalls 数组
- `tool_result`：匹配 toolCallId 更新 toolResults，标记成功或失败
- `error`：设置消息 error 字段，状态设为 `error`
- `done`：消息状态设为 `done`

错误码：

- `WORKSPACE_OFFLINE`：工作区离线
- `REQUEST_TIMEOUT`：请求超时
- `RATE_LIMITED`：限流
- `EXTENSION_ERROR`：扩展端错误
- `CHAT_STREAM_ERROR`：流式处理错误

## 九、前端与后端错误处理

### 统一 API 响应格式

```typescript
// 成功响应
interface ApiSuccess<T> {
  ok: true;
  payload: T;
  error: null;
}

// 失败响应
interface ApiFailure {
  ok: false;
  payload: null;
  error: {
    code: string;
    message: string;
    detail?: string;
    requestId?: string;
  };
}

type ApiResponse<T> = ApiSuccess<T> | ApiFailure;
```

### 错误码定义

| 错误码 | 说明 | HTTP 状态码 |
|--------|------|-------------|
| `UNAUTHORIZED` | 未认证或 Token 无效 | 401 |
| `TOKEN_INVALID` | Token 已过期或无效 | 401 |
| `FORBIDDEN` | 无权访问工作区 | 403 |
| `WORKSPACE_NOT_FOUND` | 工作区不存在 | 404 |
| `INSTANCE_NOT_FOUND` | 实例不存在 | 404 |
| `WORKSPACE_OFFLINE` | 工作区离线 | 409/503 |
| `REQUEST_TIMEOUT` | 请求超时 | 504 |
| `RATE_LIMITED` | 请求限流 | 429 |
| `HISTORY_DISABLED` | 历史记录未开启 | 409 |
| `EXTENSION_ERROR` | 扩展端错误 | 502 |
| `CHAT_STREAM_ERROR` | 流式处理错误 | 500 |
| `INTERNAL_ERROR` | 服务端内部错误 | 500 |

### 错误恢复策略

| 错误类型 | 前端动作 | 用户提示 |
|----------|----------|----------|
| 未认证 | 清理本地 Token，跳转登录页 | 登录已过期，请重新登录 |
| 工作区离线 | 禁用输入，显示刷新按钮 | 工作区已离线，请选择其他工作区 |
| 请求超时 | 显示重试按钮 | 请求超时，请检查网络后重试 |
| 限流 | 显示冷却倒计时 | 请求过于频繁，请 {seconds} 秒后再试 |
| 历史记录未开启 | 以普通提示展示 | 当前项目未开启日志保存 |
| 扩展端错误 | 展示脱敏错误，显示 requestId | 服务端错误，请稍后再试（requestId 可复制） |
| 流式中断 | 保留已生成内容，追加中断提示 | 连接中断，消息可能不完整 |

### 请求安全要求

- 生产环境必须使用 HTTPS
- 后端 CORS 只允许可信前端源，不允许 `Access-Control-Allow-Origin: *` 与鉴权接口随意组合
- 请求拦截器不得向第三方地址附加 Authorization
- 失败重试时不得在日志中输出 Authorization 和聊天正文
- 超时控制和取消控制作为请求封装的一部分
- 工具调用参数和结果展示需要转义
- 错误信息脱敏，不展示后端内部堆栈、Token、文件系统敏感路径

## 十、安全要求

- **Token 存储安全**：
  - 浏览器本地 token 保存前必须提示风险：请勿在公共电脑或不可信环境保存 Token
  - token 展示必须脱敏：前四位和后四位，中间星号；短 token 全部星号
  - 支持"仅本次会话保存"选项（sessionStorage）
  - 退出登录时必须清理 localStorage 和 sessionStorage 中的 Token
  - Base64 编码只能混淆，不能防止 XSS 攻击
- **请求安全**：
  - 请求日志不得记录 token
  - 聊天正文默认不进入浏览器控制台日志
  - 聊天消息默认使用文本渲染，不使用 v-html
  - 如后续支持 Markdown，必须使用可信 Markdown 渲染器和 HTML sanitize
- **交互安全**：
  - 自动发送开关默认关闭
  - 加载历史记录按钮需要用户主动点击
  - 发送前可选确认敏感内容
- **内容安全**：
  - 多语言文案不得泄露敏感内容
  - 工具调用参数和结果展示需要转义
  - 错误信息脱敏，不展示内部堆栈、Token、文件系统敏感路径
