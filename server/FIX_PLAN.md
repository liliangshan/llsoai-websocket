# 专家审查问题修复清单

## 目标

集中修复专家审查指出的协议一致性、并发安全、流式响应、等待请求状态机、鉴权治理、限流、去重和消息大小限制问题。

## 必须修复项

- [x] 网络套接字连接字段并发读写风险。
- [x] 握手阶段缺少工作区标识校验。
- [x] 握手阶段缺少分阶段超时。
- [x] 缺少 `client.heartbeat_pong` 处理。
- [x] 协议版本判断过严。
- [x] WebSocket 消息大小限制缺失。
- [x] SSE 响应头没有提前刷新。
- [x] SSE 心跳保活缺失。
- [x] SSE 断开未标记 `sse_disconnected`。
- [x] 流式事件通道满时静默丢弃。
- [x] Pending 并发关闭存在 panic 风险。
- [x] 普通聊天最终响应缺少兜底和字段提取。
- [x] 历史记录响应大小限制未实现。
- [x] HTTP API Key 明文比较。
- [x] API Key 建议支持哈希或环境变量注入。
- [x] 限流缺失。
- [x] `messageId` 与 `dedupeKey` 去重缺失。
- [x] 错误码不完全统一。
- [x] 同实例重连旧连接误删新连接风险。

## 本轮修复说明

- 为 `Client` 增加快照、状态更新和上下文更新方法，避免直接并发读写字段。
- 为 `PendingRequest` 增加一次性完成状态，避免重复关闭通道或向已关闭通道发送。
- 修复同实例重连旧连接清理时误删新连接索引的问题。
- 增加握手阶段工作区校验、握手超时、上下文超时、协议主版本兼容判断。
- 增加 WebSocket 读取大小限制和 `client.heartbeat_pong` 处理。
- 修复 SSE 响应头提前刷新、心跳保活、断开清理和流式写入超时。
- 修复普通聊天最终响应兜底，并规范化最终响应字段。
- 增加历史记录响应总大小和单条消息大小限制。
- 将 HTTP API Key 认证改为哈希后常量时间比较。
- 增加基础限流和 `messageId`、`dedupeKey` 去重。
- 统一部分非方案错误码。

## 完成标准

- `go test ./...` 通过。
- `go test -race ./...` 通过。
- 新增或修改代码后无已知编译错误。
- 主要协议行为与方案文档保持一致。
